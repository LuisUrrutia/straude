# Straude

**Strava for Claude Code.**

Track your Claude Code usage. Share your sessions. Climb the leaderboard.

## Why?

Running used to be solitary. Then Strava made it social. 

In 2025, a new solitary activity emerged: vibe coding with Claude Code. People are [spending thousands of dollars](https://www.wsj.com/tech/ai/anthropic-claude-code-ai-7a46460e) building with AI — but there's no way to share the journey.

Straude changes that. Import your usage, flex your stats, and see how you stack up globally.

## Features

- **Track** — Import sessions via [ccusage](https://github.com/ryoppippi/ccusage). See cost ($), tokens, time, and lines changed.
- **Share** — Post sessions with descriptions and screenshots of what you shipped.
- **Connect** — Follow other builders. Like and comment on their work.
- **Compete** — Global leaderboard with daily/weekly/monthly/all-time views, filterable by region.

## Privacy

Your choice: go public and compete on the leaderboard, or stay private and share only with followers.
